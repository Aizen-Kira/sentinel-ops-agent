# Build Reproducibility Report (V1.0.0)

## Goal
Ensure the distribution artifacts (`.whl` and `.tar.gz`) generated by the build system are deterministic and identical across distinct builds.

## Methodology
The PEP-517 build backend (`hatchling`) was invoked multiple times sequentially, with the `dist/` directory completely purged between executions. The SHA-256 hashes of the resulting artifacts were computed and compared.

## Verification Log
**Run 1:**
- `sentinelmcp-0.1.0-py3-none-any.whl`
- `sentinelmcp-0.1.0.tar.gz`

**Run 2:**
- `sentinelmcp-0.1.0-py3-none-any.whl`
- `sentinelmcp-0.1.0.tar.gz`

**Output of `Compare-Object`**: 
```text
(No differences detected)
```

## Conclusion
The build process is fully reproducible and deterministic. The exact hashes are verified and tracked within the final Release Manifest.
